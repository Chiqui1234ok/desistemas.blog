Discord ha anunciado el desarrollo de un [nuevo cliente basado en Rust](https://www.techpowerup.com/354550/discord-is-rebuilding-its-app-in-rust-early-build-uses-just-290-mb-of-ram) para su aplicación de chat. Esta iniciativa incluye una nueva versión para Linux que ofrece soporte adecuado para distribuciones modernas, un rendimiento mejorado, un menor consumo de recursos y una paridad de funciones con la experiencia de usuario en Windows. Tras este anuncio, el director técnico de la compañía, Stanislav Vishnevskiy, compartió un vídeo en la plataforma X mostrando las capacidades de esta nueva versión.

En la demostración, Vishnevskiy [compartió](https://x.com/svishnevskiy/status/2121671429402005624) lo que parece ser un overlay funcional de Discord ejecutándose en Fedora 44 mientras jugaba a WoW Forever. El overlay se muestra totalmente personalizable y cuenta con soporte completo para el chat, la pantalla compartida y las notificaciones. Este avance se produce poco después de que se anunciara la implementación de [actualizaciones automáticas en Linux](https://www.techpowerup.com/349099/discord-gets-massively-improved-linux-support-and-official-fedora-and-arch-packages).

Históricamente, la aplicación de Discord en Linux, Windows y macOS ha funcionado como un envoltorio de Electron para la versión web de la plataforma. Esta arquitectura ha generado dificultades de compatibilidad con ciertas características de seguridad de Linux, como Wayland, lo que ha impedido que los usuarios de Linux accedan a funciones críticas como el overlay de juego. La transición hacia un cliente optimizado busca mitigar estas limitaciones y mejorar la integración en el ecosistema de escritorio.
