Una nueva solicitud de patente presentada por Microsoft Technology Licensing describe un método para aprovechar la capacidad de cómputo sobrante en dispositivos domésticos con el fin de entrenar modelos de inteligencia artificial. El documento, titulado "Opportunistic Micro-training on Edge Devices Using Spare GPU Utilization" ([US-20260349820-A1](https://ppubs.uspto.gov/api/pdf/downloadPdf/US-20260349820-A1?source=US-PGPUB&requestToken=eyJzdWIiOiJlY2FlY2NjYS1mY2I1LTQ5MzctYWRkNy1mMzQwZDVhYzg0MjYiLCJ2ZXIiOiJiNDY4ODA5OS0zNWZjLTQyZGYtYWE2OC1hYjZmODI4YzczYmIiLCJleHAiOjB9)), propone fragmentar grandes tareas de entrenamiento en pequeñas micro-tareas adaptadas a la capacidad de cada dispositivo. Estas tareas se enviarían a teléfonos inteligentes, portátiles y ordenadores de gaming siempre que estos se encuentren en estado de inactividad.

## Funcionamiento y sistema de recompensas

El sistema requiere que los usuarios opten por participar de manera explícita. Una vez aceptado, la plataforma podría realizar un seguimiento del trabajo ejecutado para aplicar créditos en la cuenta del propietario. Estos créditos podrían ser canjeados por software gratuito, acceso a los modelos de IA entrenados o incluso compensaciones económicas.

Para garantizar que el proceso no interfiera con el uso habitual del hardware, el sistema monitoriza constantemente la carga de la CPU y la GPU, el uso de la memoria, la temperatura y el consumo de energía. Las tareas pueden pausarse o detenerse automáticamente si se alcanzan determinados límites térmicos o de potencia. Además, para asegurar la integridad de los procesos, los resultados se contrastan entre distintos dispositivos con el objetivo de detectar trabajos defectuosos o manipulados.

## Incertidumbres técnicas

La documentación presentada no detalla las tasas de compensación ni especifica qué hardware será compatible con este servicio. Asimismo, dado que Microsoft no ha anunciado todavía ninguna integración oficial con Windows o Xbox, no es posible determinar si las recompensas ofrecidas cubrirían el incremento en el consumo eléctrico derivado de estas tareas. Cabe destacar que, al tratarse de una solicitud de patente, no existe garantía de que el proyecto se convierta finalmente en un producto comercial.
